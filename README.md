# Post-Quantum-Secure-IoT-Communication
 A bare-metal Post-Quantum Cryptography (PQC) secure client-server communication channel for RISC-V IoT devices, featuring ML-KEM (Kyber) key encapsulation via wolfSSL, AES payload encryption, and LiteX/Verilator simulation.Key Features Client-Server Architecture: Low-level TCP/UDP socket communication running on a bare-metal RISC-V emulator (LiteX + Verilator). Post-Quantum Key Exchange: Secure key derivation using standardized ML-KEM (Kyber). Authenticated Encryption: Symmetric AES encryption and decryption of payloads using the PQC-derived shared secret. Advanced Integrations (Stretch Goals): Optional DTLS 1.3 handshake and ML-DSA mutual authentication.
